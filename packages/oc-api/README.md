# oc-api — API cloud OPTIONNELLE (plus tard)

Ce dossier est volontairement vide de code pour l'instant (cahier des charges, section 9).

## Rôle prévu

- **Préparer des corrigés** à l'avance, en ligne (par exemple avec Claude), puis les exporter
  sous forme de **packs** (`oc-pack/1`) utilisables hors ligne.
- **Synchroniser / sauvegarder** les résultats d'une classe quand Internet est disponible.

## Règles qui ne changeront pas

1. **Jamais nécessaire pour corriger.** Toute la correction se fait sur le téléphone (oc-core).
2. **Accord explicite, requête par requête.** Aucune donnée d'élève n'est envoyée sans que
   l'enseignant valide l'envoi précis. L'indicateur 🔵 Cloud s'allume seulement pendant ces envois.
3. **Fonction marquée « Internet requis »** et désactivée hors ligne, jamais de faux mode hors ligne.
